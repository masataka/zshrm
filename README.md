# zshrm

zshの実行履歴を効率的に管理・整理するためのCLIツールです。Deno製。
開発中に頻発する重複コマンド（ビルド、テスト等）による履歴の汚れを解消し、過去のコマンドへのアクセス性を向上させます。

## インストール (Installation)

### 1. Denoのインストール

このツールを使用するには Deno
ランタイムが必要です。まだインストールしていない場合は、以下のコマンドを実行してください。

**macOS / Linux:**

```bash
curl -fsSL https://deno.land/install.sh | sh
```

### 2. zshrmのセットアップ

リポジトリをダウンロードし、インストールコマンドを実行します。

```bash
# 1. リポジトリをクローン（ダウンロード）
git clone https://github.com/masataka/zshrm.git

# 2. ディレクトリへ移動
cd zshrm

# 3. インストールを実行
deno task install
```

### 3. パスの設定（コマンドが見つからない場合）

インストール完了後、`zshrm: command not found`
と表示される場合は、Denoのインストール先（`~/.deno/bin`）にパスを通す必要があります。

`.zshrc` ファイルに以下を追記してください：

```bash
export PATH="$HOME/.deno/bin:$PATH"
```

設定を反映させるにはターミナルを再起動するか、`source ~/.zshrc` を実行します。

## 概要 (Overview)

zsh標準のヒストリーファイル（通常
`~/.zsh_history`）を解析し、重複の削除や検索、対話的な管理機能を提供します。

## 機能 (Features)

### 1. 重複整理 (Deduplicate)

同じコマンドが履歴内に複数存在する場合、**最新の実行履歴のみを残して**過去の重複分を削除します。
これにより、`Ctrl+R` での検索効率が劇的に向上します。

### 2. 履歴削除 (Clear / Delete)

履歴を削除します。変更時には確認プロンプトが表示されます（`--force`
でスキップ可能）。

- **全削除 (`clear`)**: 引数なしで実行すると、全ての履歴を削除します。
- **検索削除 (`delete <query>`)**:
  指定した文字列を含む履歴のみを検索して削除します。

### 3. 対話的削除・管理 (UI / Search)

ターミナル上で履歴を一覧表示（TUI: Text User
Interface）し、インタラクティブに操作します。
実行中は全画面モード（代替画面バッファ）に切り替わり、ウィンドウサイズに合わせてリストを表示します。終了後は元の画面を復元します。

- 引数なし: 全履歴を表示。
- 引数あり: 検索キーワードとして扱い、ヒットした履歴のみを表示。

#### UIモードの操作

- **↑ / ↓**: カーソル移動
- **Space**: 選択/選択解除
- **Enter**: 選択した項目を削除（確認ダイアログあり）
- **q / Esc / Ctrl+C**: 終了

## コマンド仕様

| コマンド               | 説明                                                                       |
| ---------------------- | -------------------------------------------------------------------------- |
| `zshrm dedup`          | 重複を削除し、一意な履歴のみにする（最新優先）                             |
| `zshrm clear`          | 履歴を全て削除する（確認あり）。                                           |
| `zshrm delete <query>` | 指定したキーワードにヒットする履歴を削除する（確認あり）。                 |
| `zshrm ui [query]`     | スクリーンモード（対話モード）を起動する。`query` 指定時は検索結果を表示。 |

### オプション

- `-f, --force`: `clear` / `delete`
  コマンド実行時の確認プロンプトをスキップします。

### 隠しコマンド (Development)

開発・テスト用に以下のコマンドが利用可能です（ヘルプには表示されません）。

- `zshrm test-gen`: カレントディレクトリにダミーの履歴ファイル
  `dummy_zsh_history` を生成します。
- `zshrm test-clean`: 生成した `dummy_zsh_history` を削除します。

## 技術スタック

- Runtime: Deno
- Language: TypeScript
- Shell: zsh

## コンフィグレーション

- 読み込むヒストリーファイルのパスは環境変数 `HISTFILE`
  を参照、またはデフォルトで `~/.zsh_history` を使用。
- `EXTENDED_HISTORY`
  フォーマット（`: <timestamp>:<duration>;<command>`）および標準フォーマットに対応しています。
